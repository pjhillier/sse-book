# The Security-Engineering Convergence — pre-publication website

This is the **actual drafted website copy and layout**, based on the publication-preparation manuscript's chapter and appendix headings, approved author biography and book positioning. It is a self-contained static site intended for `pjhillier/sse-book`.

## Safety and status

- The manuscript is **not included**; the repository can remain **private**.
- No PDF or other book download link is active; there is **no fake DOI or ISBN**.
- Intended book licence is **CC BY 4.0 upon publication, after rights review**; this website is **not** a declaration that the manuscript has been published under that licence.
- The front cover is a working approved cover concept, not evidence of final print-production approval.
- The manuscript's seven parts, 28 chapter headings and seven appendix titles are transcribed from the current publication-preparation interior.

## Preview on Windows PC

1. Download and extract the ZIP file.
2. Double-click `index.html` to preview in Edge, Chrome or Firefox.
3. Keep `cover.png` alongside `index.html`.
4. Read each section and note any wording or presentation changes desired.

## Upload to the private GitHub repository

1. Sign in at https://github.com/pjhillier/sse-book using a PC browser.
2. On the **Code** tab, select **Add file → Upload files** (or use the upload option offered by GitHub's current interface).
3. Upload **the individual files** `index.html`, `cover.png`, `README.md`. Do not upload the enclosing ZIP as the website itself.
4. Review filenames at repository root and choose **Commit changes**.
5. Keep the repository **Private** until the technical, editorial and third-party-rights release decisions are complete.

**Note:** GitHub Pages hosting on a GitHub Free plan requires a public repository. Do not turn it on for this private working draft. To preview before publication, use the local `index.html` as above.
